# Webtech-Exp10
Aim :
To design web pages using HTML, CSS, and AngularJS to perform form validation and implement routing between multiple pages.

Description:
AngularJS is a JavaScript framework used to develop dynamic web applications. It provides form validation to check user inputs and display error messages for invalid fields. The ngRoute module enables navigation between multiple pages without reloading the entire application.

Procedure:

1.	Open Visual Studio Code and create an HTML file named index.html.
2.	Create the basic HTML5 structure using the required tags.
3.	Include the AngularJS library and angular-route.js using CDN links.
4.	Initialize the AngularJS application using the ng-app directive.
5.	Create an AngularJS controller to handle form data.
6.	Design a form with input fields such as name, email, and password.
7.	Use AngularJS validation directives like required, ng-minlength, and ng-pattern to validate user inputs.
8.	Display error messages for invalid fields using AngularJS validation properties.
9.	Configure page navigation using the $routeProvider service.
10.	Create multiple HTML views and connect them using ngRoute.
11.	Use navigation links to move between pages without reloading the application.
12.	Save the files and run the application in a browser to verify form validation and page navigation.
